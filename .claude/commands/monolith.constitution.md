# monolith.constitution

Create or update the project constitution at `.monolith/memory/constitution.md`.

Steps:
1. Read the existing constitution if one exists.
2. Ask the user three questions:
   - What problem does this project solve and for whom?
   - What are the 3–7 non-negotiable engineering principles?
   - What is the definition of done for a task?
3. Write or update `.monolith/memory/constitution.md` with their answers.
4. Keep it under one page — this file is read on every task.

Stop after writing. Do NOT start any implementation.
